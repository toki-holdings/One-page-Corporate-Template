会社ラク経営

在庫、販売、費用、給与、社員情報をひとつにまとめる小規模事業者向け業務管理アプリです。

Mac / Windows 版をダウンロード スマホ版を開く

デスクトップ版

Mac はアプリを開くだけで利用できます。Windows は同梱の起動ファイルから利用できます。

スマホ版

Safari や Chrome から開き、ホーム画面に追加して利用できます。

クラウド同期

ログインと同期は api.toki-holdings.jp 経由で行い、ユーザー端末から Supabase へ直接接続しません。

初回リリース前に、メールログインとデータ同期が本番ドメインで動作することを確認してください。
